# Docker Lab

Laboratório pessoal para estudos, testes e criação de ambientes reutilizáveis com Docker.

O objetivo deste repositório é aprender Docker na prática, entendendo conceitos como imagens, containers, Dockerfiles, volumes e redes, além de criar ambientes que possam ser reproduzidos facilmente.

## Projetos

### yt-dlp

Ambiente Docker para utilização do `yt-dlp`.

O projeto está sendo construído passo a passo, começando com uma imagem base do Ubuntu 26.04 e adicionando somente as dependências necessárias.

Estrutura atual:

```text
docker-lab/
├── README.md
└── yt-dlp/
    └── Dockerfile
```

## Ambiente

* Docker
* Ubuntu 26.04 como imagem base inicial
* Python 3.14

Mais ferramentas e configurações serão adicionadas conforme a evolução dos projetos.
